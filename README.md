# mitx-6002-simulation-lab

**MITx 6.00.2x — Introduction to Computational Thinking and Data Science**

Simulações em Python: propagação viral, random walks de robôs e tendências climáticas.

| Módulo | Conteúdo | Comando |
|--------|----------|---------|
| `virus_spread` | Simulação estocástica de vírus (pset3) | `python virus_spread/run.py` |
| `robot_clustering` | Random walk + pset2 original | `python robot_clustering/demo_robots.py` |
| `climate_trends` | Regressão em séries de temperatura | `python climate_trends/run.py` |

## Setup
